## 时序候选与证据范围

入口校时候选沿用两帧确认、回跳检测和当前扫描健康检查，根据当时已经收到的信息纠正时间戳。出现额外几何告警、校时失证或校正后非单调的时间戳，便停止候选输出。分支运行于独立 ROS 原生实例，使用可丢弃的试验地图。原生地图写回门及拒绝分支仍由冻结版的回放验收覆盖。

比较表将候选工作地图的轨迹与已接回的正式输出分开。正式验收需具备生产入口的逐帧证据，核对候选状态与正式状态接回一致，并验证错误提交、误干预与新增停发。
