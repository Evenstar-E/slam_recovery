# 最新提交复审 · 第五宿主与组件消融实验计划

**审阅对象**：[357c473](https://github.com/Evenstar-E/slam_recovery/commit/357c473458a81a976b1f9690d39f6831f164f054)。这笔提交只给计划新增 48 行，提出 FAST-LIVO2 第五宿主（P11）和组件消融（P12）。在它的 Git 树中尚无这两个新实验的结果清单。上一笔架构图和现有执行代码的评审、18 项测试结果及边界反例见[配套复审](../review_20261106_a14bc1c/README.md)。

**结论**：两组实验都值得做。P11 能回答原生紧耦合宿主是否已经足够稳健，P12 能检验每个判断条件是否改变了真实决策。按现稿直接开跑会出现三个解释困难：把预期百分比当验收目标、删掉了与实际实现不同的条件，以及用开发中反复看过的场景作独立泛化证据。

**建议顺序**：先锁定候选与独立标签，修正缺证据提交，跑一次四门的受控决策对照；随后做第五宿主单地点 clean/fault 配对。将真实结果写入论文前，核对实际输出来源、正常运行的误干预以及是否真的改进了地图和轨迹。开发计划中的预期值不作实测结果。
