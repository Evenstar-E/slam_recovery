## 接受

Q与实际C3同区域、同query、双向绝对计数，避免不同总体ratio拼净分；proxy非GT和离线非部署限定正确。两臂可作为M3第一步“修复相对只隔离”对照，不等于已完成原生/无条件/验证准入完整策略消融。

## 运行前须定义（P2协议缺口）

第134行“proxy restricted to common support of both arms”若指两地图已覆盖区域的交集，会把C3新恢复而Q没覆盖的区域从分母删掉，正好抹掉要测的增量。用预先冻结、独立于两输出的空间ROI/query ID（含待恢复区域），unsupported和missing留在分母。若仅指相同采集机会/可评价时间，明确该含义，不以map支持决定ROI。

Q应使用与C3相同的冻结pre-onset可信底图；C3评价图为“该底图 + 实际重估后的新增贡献”，否则比较两张从不同prefix重估出的地图，新增差异混入底图变化。另列底图变化/对齐控制即可，不能把重跑整个prefix的差异计为修复增量。

“C3 adds points Q does not have”不能用浮点点值集合差定义：不同抽样/密度会制造新增点。固定体素/表面单元及容差定义，按同query覆盖状态Q=false,C3=true统计新增proxy覆盖，同时报reverse变化；map新增贡献按key/原point ID追溯，输出采样与体素规则预注册。
