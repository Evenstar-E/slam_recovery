# 远程 WSL 三宿主的 VIO 恢复核验

回放、宿主子进程、外部订阅和评分运行在远程 WSL `tzr@windows11`。本机 WSL 用于编辑、编译适配器和生成报告。远端证据保存在 `/home/tzr/vio-gate-20261127`。每臂使用 950 对 EuRoC 图像，输入进程按 1×独立送入。输入未暂停与宿主能实时处理是两个独立的验收条件。

## 改动与配置

- ORB-SLAM3 增加可选 `--adaptive-gate`。按故障前锚点与首个健康恢复帧的原始匹配分布选择留出区域，然后在整个事件内固定。拟合端看不到留出的像素。原先至少 12 个独立内点改为至少 8 个、内点比例至少 60%、前后帧各至少两个区域提供内点，每个区域至少两个。保留原位置 0.20 m、姿态 5°、重投影 4 px 判定和连续三帧要求。
- VINS-Fusion 和 OKVIS2 共用检测、隔离、备用实例、短后缀、原坐标核验和外部订阅。原生适配器只接双目、IMU 和宿主输出。两臂均使用该宿主同一个工作配置。VINS-Fusion 为 `be55a937` 的同步双目惯性 `Estimator`，回环节点未接入。OKVIS2 为 `a2ea0068` 的 `ThreadedSlam` 配置。两者保留主路和备用实例，尚无它们的原生持久快照验证。
- VINS-Fusion 的初版适配器把估计器分配在栈上。回溯定位到原生构造函数读取尚未初始化的边缘化指针。适配器改用原生入口的静态存储方式后，两臂均用同一修正版重跑。保留启动失败和诊断报告。
- EuRoC V2_01 的短、长遮挡为 25–25.35 s 和 38–39.70 s。V2_02 固定为 25–25.35 s 和 38–38.35 s。故障窗只用于注入和事后评分。Vicon 只用于事后评价。每臂以故障前片段对齐，在共同具备外部真值的原坐标帧上比较误差。

## 决策证据

- ORB-SLAM3 的 V2_02 自适应臂两次都获得了备用检查点，但各 23 帧候选均未通过。第二次全部缺匹配。固定臂第一次停在备用检查点差异，故这轮第一次的 A/B 准入差异不能单独归因于门限。V2_01 的短遮挡补齐 7/7 帧，长遮挡在备用资格未恢复时拒绝。无注入没有隔离。
- OKVIS2 短遮挡的 7 帧从原坐标送到外部订阅端，长遮挡按候选窗口上限拒绝，拒绝后公开输出标记为坐标未验证。主路和备用实例串行更新使延迟上升，虽然共同帧位置误差略有改善，一秒内有效输出明显下降。
- VINS-Fusion 双事件外部回执已核。事件 1 接回且送达 7 个盲段帧，事件 2 拒绝（bounded_candidate_window）。
- OKVIS2 无注入的隔离次数为 0。
- VINS-Fusion 无注入的隔离次数为 0。

本次保留了完整的事件、输入身份、外部回执、配置、退出状态与 SHA-256。VIO 单元测试通过 14 项，两种原生适配器均用同一构建脚本生成，二进制与源码哈希保存在远端。
