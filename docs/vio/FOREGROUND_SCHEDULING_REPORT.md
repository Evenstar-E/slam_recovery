# VIO 前台优先调度与原生计时

在远程 WSL tzr@windows11 上用 EuRoC V2_01 的同一份 950 帧输入回放。录制按 1×独立送入。沿用短全遮挡 25–25.35 s 和长全遮挡 38–39.70 s。故障标签不参与检测和准入。输出用外部订阅回执核验。

## 实现

- 插件调度器在后台按物理帧顺序更新备用实例。主路按自己的求解进度发布，无须等待同帧备用求解。双事件间的旧主路追赶也走同一个后台队列。
- 背景队列最多容纳 12 项。在确认隔离时，备用最多有 50 毫秒补齐故障前边界。状态与输入必须通过原有边界核验，追不上时拒绝使用该备用。接回、历史补发和独立几何门沿用上版。
- 插件原生适配器逐帧记录管道两端的时刻、前端和优化。传输使用连续数组的 buffer view，避免额外复制出 Python bytes。VINS-Fusion 计时包住原生特征跟踪和 Estimator::optimization。OKVIS2 读取原生 DetectAndDescribe、Match、Optimise、全图优化结果导入和边缘化的计时增量。计算本身仍执行宿主原生实现。
