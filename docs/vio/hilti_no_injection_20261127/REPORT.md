# 三套 VIO 宿主的无注入对照

完成五段 Hilti 的 15 组原生／插件配对。插件的原坐标交付在 14/15 组下降，在 1/15 组增加。插件组记录 21 次隔离和 0 次候选采纳。这批结果不支持接入后普遍更稳。

本轮在远程 WSL2 对同一录制比较原生路径和完整恢复插件路径。两组均无人工故障注入，由独立进程按 1× 释放输入，并由独立订阅端确认实际收到的公开位姿。宿主源码本轮零改动。原生组通过同一计时适配器运行冻结宿主，关闭恢复控制器。ORB-SLAM3 使用已带计时和可选快照接口的冻结构建。

**Campus12 无法作为双目 VIO 输入。** 实际 ROS bag 含 4,695 帧点云、93,885 条 IMU 消息、零图像消息。三宿主两组均无法运行。原包索引见 [Campus12 证据](CAMPUS12_ROSBAG.yaml)。

## 拒绝之后的发布路径

- ORB-SLAM3 拒绝时保留原主实例，追赶缓冲输入，弱帧跳过视觉更新。拒绝分支将原坐标标志置为无效。连续三个健康结果可重新武装检测，原坐标资格仍需独立验证。
- VINS-Fusion 和 OKVIS2 拒绝时也保留原主实例，弱帧走纯 IMU。拒绝区间由主实例追赶，该分支未将区间内的历史结果交付给订阅者。后续主路继续发布标记为局部坐标的结果。
- Exp18 ORB-SLAM3 原生交付 3,080 个公开位姿，插件交付 3,059 个，其中 2,599 个为局部未验证。这 2,599 帧仍在同一地图 ID 下发布。Exp16 ORB-SLAM3 的 552 个共同原坐标帧全部在首个隔离前，所以 RMSE 改善描述的是隔离前共同段。原生组在首次可疑帧前后 0.25 秒内发布了 21 帧。
- Exp01 ORB-SLAM3 零隔离。插件组输入队列丢帧从 1,596 增到 2,508，同时有 3,132 个公开位姿来自新的地图 ID。这些是同一次运行中的观测，尚不能将地图切换单独归因于队列丢帧。

## 反例与适用范围

- Exp18 初测三套插件在录制约第 24.4 秒触发同一视觉告警。对应首帧原始双目 FAST 数为 42/89，校正后为 9/68。低的一路跌破冻结阈值 12。三个原生路径在本段仍有公开位姿。OKVIS2 在备用候选的纯惯性步等待回包超时，插件控制器提前结束。原始观测复核见 [观测证据](EXP18_RAW_EVENT_OBSERVATIONS.json)。
- Exp04 的 ORB-SLAM3 插件组未隔离，但出现标记为原坐标的漂移位姿。三个共同测绘点的 RMSE 为 1.094 m → 5.572 m。另一个只有插件组覆盖的控制点附近，插件输出离其自身起始坐标原点约 205 m。测绘点少，两个指标分别保留。见 [位姿读回](EXP04_ORB_DIVERGENCE.txt)。

完整 JSON 和逐帧 CSV 包含解码、检测、队列、前端、优化、请求/应答、追赶等各宿主可测分段。源队列达 512 项后会按冻结实现丢帧，所有丢帧计入对照。轨迹误差不能替代缺帧和停发指标。每条件一次回放，双路批次使用分开的 CPU 亲和性，仍共享机器上的内存与 I/O。
启动预检保留了 ORB 的校正模式崩溃和 VINS 的 ROS 路径错误。修正配置后二进制沿用原冻结版本。Exp18 的 OKVIS 两臂使用相同宿主配置，辅助门控标定文件的 Camera.type 标签不同，门控只读取该文件的数值和矩阵，内容一致。见 [配对配置核验](PAIR_CONFIG_CHECK.json) 和 [完整验收摘要](AUDIT.json)。
