# ORB-SLAM3 异步追赶复验

2026-11-27，香港时间。基于现有 VIO 工作树和 EuRoC V2_01_easy。所有 1× 驱动读取前 950 对图像，外部订阅进程逐条回执。保留原 0.5 米、一秒内送达评分与故障准入门。一个接收时间戳的差值只按墙钟统计。

## 接入

恢复模式通过 --async-recovery 启用。只有恢复备用的后缀、隔离中的私有候选和旧主路的短窗追赶跳过逐帧排空。主路正常跟踪、常规备用镜像和保存可信快照保留原路径。新 worker 的握手拒绝不支持该协议的旧二进制。

隔离口先读回主路和备用在同一物理戳的同步状态，再执行原一致性门。候选三帧的留出视觉门及其历史估计继续保留。交接前同步末帧，获取活动图、位姿、速度、偏置与预积分，并对比同步前状态和留出几何。同步未就绪、图身份变化或核验失败沿既有拒绝分支。原生局部 BA 和回环继续运行。

## 固定追赶窗

同一个第 229 帧原生快照，后续 95 对原图和完全相同的 IMU，顺序为同步、异步、异步、同步。每一臂都在末尾执行新版同步读取。含末尾同步，逐帧等待用时 3.55–3.57 秒，异步用时 2.43–2.52 秒，短了约 29%–32%。四臂均跟踪 95 帧、队列归零、末帧通过原一致性阈值。两次异步与第一个同步末帧的位置差分别为 1.48 和 1.36 厘米。

## 1× 活流

首轮异步短遮挡有 7 帧惯性历史和 3 帧视觉修复的实际回执，E1 接回后重新武装，E2 因候选窗口耗尽拒绝。异步和同步最长停发都对应物理输入 37.95–40.15 秒，即长遮挡和后续再入。两者处理该段时队列状态不同，停发时间受积压影响。

反序中的异步臂以更早的第 204 帧快照恢复，虽然追平活输入，E1 的备用验证报告关键帧数相差 3，超过当时的原有门槛。该臂两次拒绝，未发布原坐标修复历史。结果保留异步功能和端点硬门，异步路径继续作为显式开关。这轮不能据追平速度认定跨运行的修复交付已经稳定。

两种运行的真正缺口分别是长遮挡区间的公开输出策略，以及较旧快照异步重放后达到活地图一致性的可靠性。结果仅覆盖本开发序列。详见 [结果及收据散列](ASYNC_RECOVERY_RESULTS.json)。
