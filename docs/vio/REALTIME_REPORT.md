2026-11-27（香港时间）。沿用 `V2_01_easy` 的前 950 组双目惯性输入、25.00–25.35 秒及 38.00–39.70 秒两段完全双目遮挡。原生臂保留 Atlas。两臂同一 ORB 库、标定、构建、局部建图排空选项和注入规则。保留原开发序列与本轮之前的离线证据。

## 遮挡历史与外部交付

短遮挡采用故障前原生位姿、速度及 IMU 偏置，对原始 IMU 逐样本积分。候选首先用保留图像区域做独立验证，随后用首个通过验证的后缀位姿检查惯性预测，最后在两端之间分布校正。离线预验和 1× 回放均覆盖短遮挡的 **7/7** 个物理帧，且收到后缀 3 条视觉历史。主 1× 实验闭合前的位置和姿态差分别为 **18.7 mm** 和 **0.131°**。

由独立 Unix socket 订阅进程写接收记录并逐条应答。按交付编号、物理纳秒戳、位姿和标记逐条与控制器回执核对。10 条历史均在第三个视觉验证帧已到达后交付。长遮挡有 34 个物理帧。1.50 秒候选窗口结束时仍全遮挡，拒绝原坐标历史；复明后恢复标记为原坐标未验证的局部轨迹。该臂实际交付 147 条此类局部位姿。
