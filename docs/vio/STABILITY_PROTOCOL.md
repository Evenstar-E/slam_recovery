# VIO 稳定性矩阵和验收口径

2026-11-27（香港时间）。问题是增量 ORB‑SLAM3 恢复插件能否增加可及时使用的轨迹，同时维持无注入时的表现。固定双目+IMU、原生 Atlas 公平对照、1× 不暂停输入、相同 950 对图像及 IMU。故障尺寸、检测阈值、几何及惯性门限沿用 `6edbd50`。旧结果提供问题线索，保留原件。

同一采集内的遮挡和帧相关。分析单位为序列×条件×成组重复，报告配对差及各重复的范围，帧数仅用于覆盖和误差分母。独立采集数不足以支持显著性或跨数据集泛化估计。保留低可见度、原生失跟、进程失败和各种拒绝。数据开始前的顺序、配对和版本放入运行收据。

## 主要和次要结果

- **首要结果为及时且可用的位姿覆盖。** 以在独立 Vicon 观测支持范围内、距首次输入至少 8 s 的所有物理帧作分母。入分位姿须为原坐标已验证、以同一故障前规则刚体对齐后位置误差 ≤0.50 m，并于该帧的实际输入后 1.0 秒内抵达独立订阅端。每组还单独报告准时输出、坐标已验证输出、合格误差输出，定位失败环节。
- **次要结果为稳定性代价和可解释性。** 独立输出的 p95 墙钟延迟、停发、接回延迟、共有帧 RMSE、各臂覆盖与误差、短遮挡历史、拒绝与局部未验证输出、原生失跟与地图切换、实际输入／交付数量。不以共有帧 RMSE 掩盖缺失位姿。复明后未知坐标不作为原坐标恢复。重复与两序列各自展示。
- **诊断判据。** 无注入要求 0 误隔离，及时可用覆盖相对原生下降不超过 1 个百分点，p95 广播延迟加重不超过 0.25 秒。故障条件要求及时可用覆盖多至少 5 个物理帧，p95 广播延迟加重不超过 0.25 秒，并保留长窗安全拒绝。若任一必要条件重现为失败，报告具体限制。该判据只评估稳定性，现有 ORB 接纳门限不因评分改动。

先固定诊断臂并完成诊断再选机制。仅在 V1/V2 已看过的开发数据上决定改动，之后冻结源码和判断再看 V2_02。短遮挡和长遮挡仍是同一种图像故障的不同持续时间。推广到其他故障类型和其他 VIO 宿主需另外验证。
