3. **单元测试：**保留并复用已验证测试；改动范围内运行相关回归，已复现正常缺陷用最小反例加必要正例验收。未变源码不每轮重跑全套，文档变化不重跑宿主，不以测试条数增长或极端异常矩阵作为进展。独立Codex复现属于新环境验证，不算重复开发，但不重写同一套工具。

### 2.1 多次调参后，先分析规律和上限，再决定换算法

用已有run/receipt汇总，不先发起新的大矩阵、不重新跑已有结果。调参仍属于开发证据，不能在同一序列调好后称独立确认。区分**算法超参数**和**冻结的科学验收/准入阈值**；后者不能作为改善成绩的旋钮。

每次进入再次调参的决策前，交一份简短、可追溯的总结（无重复调参则不强制填无意义表）：

- **变化轨迹：**baseline→各轮实际参数值、改动假设、固定source/input/evaluation版本和run证据。不同版本或人口的结果不直接拼成参数趋势。
- **规律：**参数增减如何影响污染残留、健康误删、轨迹/地图质量、候选可用性、缺失和成本；说明单调、平台、非单调或取舍。若多参数同时改、运行方差大或证据不足，写无法区分，不能臆造曲线。
- **调整上限：**已有有效参数范围内，收益是否趋于饱和、还能改善哪一部分、会付出什么代价。复用C0/C1/C2与C3的诊断：仅改状态仍留假点、oracle去污染仍缺背景、或存在可恢复信息但实际过滤/重估失败，分别指向不同瓶颈。C1/C2是诊断而非部署成绩，不把proxy/oracle上限当已证明的理论上限；无法估计时标UNKNOWN，并提出至多一个能区分瓶颈的有限实验，非无限试参。
- **决策：**继续时说明剩余改善空间、下一唯一假设与现有预算内停止条件；停止时冻结当前参数并保留负结果。只有证据指向现有模型结构/假设瓶颈时才更换算法，写明新方法针对什么、复用哪些旧模块、如何做公平验证，不因调参次数或单次FAIL直接上更大模型。

停止继续调参的典型依据：在可接受代价内改善已平台化；只通过损害健康几何/完整度换取单指标；增益小于已观察运行不确定性而下一实验无区分力；当前输入缺可恢复信息；或达到预先声明预算。预算与有效改善标准由执行侧沿用既有约定，不在看完结果后改值。

这项总结**随下一实际算法/实验交付附上**，不另开仅“总结已完成”的循环。原则是让参数探索产生机制认识和停止决策，不把调参本身当主线成果。

### 2.2 单序列/单时段阈值：评估自适应判断与模型升级

2026-11-10用户直接指出：如果阈值依据某个序列某段确定，应考虑是否切换更高级模型及自适应判断阈值。**旧门冻结不是禁止新方法研究，也不是要求继续逐段手调常数。**

- 先用已有证据区分：噪声/参考支持/地图年龄或采样尺度变化，可评估条件化归一、自适应噪声/置信校准；当前模型无法表达时变误差/段内相对漂移、仍有可用观测，则评估更合适的窗口/可观测子空间状态重估。模型“高级”不等于更大网络，信息确实缺失时不能靠模型补出真几何。
- 对新自适应方法冻结的是更新规则、输入特征/支持范围、开发与评价数据界限及评价协议，不是要求每帧输出同一个常数。在线不得读故障真值或因当前候选被拒就调整使其通过；独立质量、完整人口和负结果要求保持。
- 已知producer坐标/正则错误先最小解除，不让新模型掩盖评价缺陷。只凭低info、被拒或人工有益标签不足以证明要换法；复用旧运行总结趋势/代价/上限后提出一个有区分力的比较，不默认新增fallback/更大模型/参数矩阵。方法变更另记版本/预注册，旧结果不改写、不混表。
- S1指定一个并行方法评估负责人，沿真正授权与已有预算组织；S2原生恢复写回/接回/E2不得再等待全部模型/阈值推导。这里是评估和交接要求，不是本机算法实现、实验或安装授权。
