# B10 预注册：同输入四策略比较（2026-11-10）

本文件在**任何新的四策略运行之前**冻结口径。写完之后再改任何一条，都要在提交信息里写明改了哪条、为什么，并且旧运行作废。

## 0. 为什么现在只能预注册、不能直接跑

归档的 `four_arm_independent_results.json`（独立复算）已经证明：现有数据里**四臂只有两张不同的地图**——`A0 ≡ A2`（同一 keyframe 列表）、`A1 ≡ A3`（门控全部拒绝，`verified_prefix=[]`，A3 退化成 A1）。也就是说，用现有归档跑不出"无条件接纳"和"门控接纳"的差别，B10 缺的不是统计方法，而是**一条会真正提交修复子集的候选流**。

所以顺序是：先由 A10/B11 的原生同进程闭环产出一条带"门 accept/reject + 候选 id"的候选流，再用本协议跑四策略。在候选流存在之前，任何四策略表都只是两张图的重复。

## 1. 输入与候选集（每次运行前冻结）

- 输入包：`room02_2x2_O.bag`（sha `f8b26ddf…`）与 `hall01_inj43.bag`（sha 以归档 receipt 为准），只跑这两个，不新增序列；
- 关键帧集合：宿主实际输出的 `/aft_mapped_to_init` 时间戳集合，四臂共用同一份；
- **候选集**：宿主隔离段产出的修复位姿，四臂共用同一份；候选的构造方式、参数、输入扫描全部在运行前写进 receipt，运行后不得重选；
- 位姿约定：SE(3)，扫描在 body 系，记录朝向必须应用（`--ignore-rotation` 只能作对照）。

## 2. 四个策略（只差准入策略）

| 臂 | 准入规则 | 未接纳帧的处理 |
|---|---|---|
| `N` 原生 | 全部接纳宿主位姿，无隔离、无门控 | 无（全部有） |
| `Q` 仅隔离 | 只接纳 onset 之前的关键帧，候选不接纳 | 计入 **missing**，不插值、不外推 |
| `U` 无条件接纳 | 隔离后**整段**接纳候选 | 无（全部有） |
| `G` 门控接纳 | 隔离后只接纳门 accept 的子集 | 门 deferred/拒绝的帧计入 **missing**，逐帧列出 |

`G` 的 `verified_prefix` 必须是门给出的结果，不允许为了"让 G 不等于 Q"而放宽阈值。

## 3. 评价人口

- **共同人口**：四臂都有的帧交集，作为主表；任一臂缺帧都必须单列，不得静默删除；
- **GT 支持人口**：hall_01 的 252 帧 GT 匹配子集，单独一列；
- **缺失**：每臂 missing 数、原因（候选未生成 / 门拒绝 / 宿主无输出）逐项列出；
- 参考面：完整干净参考 **8,490,000 点**为主；120k proxy 只作为与历史数字的对照，两套人口**不得混用或相减**。

## 4. 指标（全部必报，不给综合分）

覆盖、unsupported 比例、新增正确/错误几何、丢失的正常几何、`ATE_full_alignment_diagnostic_m`、`ATE_frozen_prefix_protocol_m`、缺失帧数、运行 wall time、峰值 RSS。

轨迹两套 ATE 并列，冻结 prefix 协议是主口径，全轨迹拟合只作诊断，不互相替代。

## 5. 统计

- 配对 bootstrap **按关键帧**重采样（不是按点；按点会把 CI 压窄约 3.2–3.5 倍），10,000 次，报 95% 区间；
- 同时给计数与比例；样本不足直接写"不足"，不报比例；
- 两个由同一份样本导出的量（例如 A1 与其 floor）之间的 CI 重叠**不构成证据**，不得据此下结论。

## 6. 外部基线（能力相符才比较）

只接受**消费同样扫描、输出位姿**的外部基线。允许：FAST-LIO2 / LIO-SAM 这类纯 LiDAR 里程计在同一 bag 上的输出。不接受：不同传感器配置、不同序列、需要人工改参才能出结果、或只报告成功率不报告轨迹的实现。无法比较的部分要写明"不可比"，不是"我们更好"。

## 7. 预注册判定

在跑之前写死：

- `G` 相对 `U`：**有害接纳减少**（按独立标签计）且 **有益接纳损失**不超过预先声明的界限；
- `G` 相对 `Q`：接纳的候选里至少有一帧被独立评价判为有益；
- `G` 相对 `N`：共同人口上的 coverage/unsupported 不劣化超过预先声明的界限。

三条里任一不满足，就按实测结果报告，不调界限。
