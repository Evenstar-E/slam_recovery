# `kappa` 区间与 `tau_abs_min` 的推导（2026-11-10，数学侧）

输入**只有** `tau_info_scale_evidence.md` 的 16 行记录。本文没有先看 r11070-c3 的离线几何重算，
因此两边可以互相校验，而不是一边拟合另一边。**不改代码、不改阈值、不碰 `core.py`。**
可复算：`python -I docs/review_20261110_b10/kappa_derivation.py`。

## 1. 判据

```
通过  ⇔  weak_dir_info_after >= kappa * weak_dir_info_before   且   gain > 0
gain  =  weak_dir_info_after - weak_dir_info_before
```

`gain > 0` 与 `ratio > 1` 等价，所以 `kappa <= 1` 时比值条件被 `gain > 0` 完全吸收。

## 2. `kappa` 的可取区间

16 行的比值（`after/before`）：

| 分组 | 行数 | 比值 |
|---|---:|---|
| 应通过（onset / icp 候选） | 9 | 3.6567, 4.0567, 4.1927, 4.2001, 4.2056, 4.2162, 4.2174, 4.2301, 4.2645 |
| 应拒绝（启动早触发、坏 icp） | 7 | 0, 0, 0.8568 ×4, 0.8845 |

**区间：`kappa ∈ (0.8845, 3.6567]`**（不加 `gain > 0` 时）；
**加上 `gain > 0` 后有效区间为 `kappa ∈ (1, 3.6567]`**。

分离度：`3.6567 / 0.8845 = 4.13`。

### 边界余量（这是本节的重点）

- **上界没有余量**。`3.6567` 就是最弱的那个"应通过"行（`051542Z`，icp）自己的比值。
  任何 `kappa > 3.6567` 都会拒掉一个本群体判为有益的候选；也就是说上界由**单条观测**定义，
  不是一个带安全余量的边界。取近似上界（如 3.5）等于用掉 4% 的余量去换确定性。
- **下界不起作用**。所有"应拒绝"行的比值都 < 1，`gain > 0` 已经把它们全部拒掉；
  `kappa` 在 (0, 1] 内取任何值都是同一条判据。下界 `0.8845` 只在**去掉 `gain > 0`** 时才成为约束。
- **区间内的选点**：若需要"离两端等相对距离"的点，对数意义下的 maximin 是
  `sqrt(1 × 3.6567) = 1.912`（含 `gain > 0`）或 `sqrt(0.8845 × 3.6567) = 1.798`（不含）。
  **这是选点约定，不是测量**；它不让区间变窄，也不提供新证据。

### 这个区间*不是*置信区间

16 行里只有 **12 个不同的比值**，且多个行是同一配置的重复（σ=0.12 那 4 行到小数点后三位相同）。
区间的两个端点分别由一个配置决定。所以准确表述是：

> **与这 16 行相容的 `kappa` 范围是 (1, 3.6567]；它不是从重复实验估出的置信区间，
> 且不能用同一批数据做验证。**

## 3. 为什么必须有绝对下限 `tau_abs_min`

纯比值在"两边都很小"时失效：

```
before = 0.01, after = 0.05   →  ratio = 5,  gain = 0.04   →  通过任意 kappa <= 5
```

但 `after = 0.05` 的信息量意味着沿弱方向的方差约 `1/0.05 = 20`，远差于门自己允许的
`sigma_tol`。**比值度量的是"变好了多少"，不是"够不够用"。**

### 判据形式

```
通过  ⇔  after >= tau_abs_min  且  after >= kappa * before  且  gain > 0
```

### `tau_abs_min` 由什么量决定：由 `sigma_tol` 测得

不是另取一个自由参数，而是**复用门里已经冻结的协方差界**。`core.py` 的 Mode 2 另一条腿是

```
p_after = || cov_after ||_2   <=  sigma_tol = 0.5
```

`||P||₂` 是协方差（**方差**）的最大特征值，所以 `sigma_tol` 在这条腿上约束的是方差。
沿弱方向的方差是 `1/λ`，于是

```
1 / lambda  <=  sigma_tol      ⇒      lambda >= 1 / sigma_tol = 2.0
```

**`tau_abs_min = 1 / sigma_tol = 2.0`（按方差读法）。**

如果 `sigma_tol` 的本意是标准差（名字像），则界变成 `1/λ <= sigma_tol²`，

```
tau_abs_min = 1 / sigma_tol² = 4.0
```

**两种读法差 2 倍，必须先由阈值的所有者确认语义，再冻结。** 这不是可以含糊过去的细节：
在这 16 行上，最弱的"应通过"候选（`051542Z`，after = 4.0293）距离

- 2.0 有 **2.01 倍**余量；
- 4.0 只有 **0.7%** 余量（4.0293 / 4.0 = 1.007）。

也就是说，若取标准差读法，`tau_abs_min` 会变成**实际约束**，且余量几乎为零；
若取方差读法，它只是防"两边都很小"的护栏，不参与本群体的判定。

**这就是"由 X 测得"的形式**：`tau_abs_min = f(sigma_tol)`，`f` 由单位约定唯一确定，
不是从数据里挑出来的数。任何形如"参考分辨率 4–5 cm → 信息量"的取法都会给出 400–700 量级，
把本群体全部拒掉，说明那个量对应的是**测量噪声信息**，不是**可接受下限**，两者不能混用。

  换了判据后信息腿不再拦它们，`G` 与 `Q` 是否仍重合要由确认性运行回答，不能沿用旧判断。
- **必须标注"旧判据"的对象**：`tau_info_scale_evidence.md` 的 16 行、
