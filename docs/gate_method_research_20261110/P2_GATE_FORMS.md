## 0. C-2 的旋转依赖：重做后的协议与两层结果

**协议（决定性的那一层）**：纯旋转（translation = 0），把变换后的信息矩阵用
`transport_information(L, G⁻¹)` **搬回 0° 的同一 anchor**，方向用 anchor 处的 `v0` 原样投影，
**全程不做再单位化**。旧 producer 若对刚体重表达协变，该值应逐位不变；任何偏离都是 producer 的。

| 来源 | 变换 | 旧 producer | C-2 |
|---|---|---:|---:|
| room02 扫描 | 纯旋转 10° | 3.65e-16 | **0.66%** |
| | 纯旋转 30° | 3.65e-16 | 0.39% |
| | 纯旋转 45° | 1.82e-16 | **20.1%** |
| | 纯平移 (2,−1,0.5) | 0 | 0.66% |
| | 完整 SE3 45° | 0 | 20.3% |
| hall01 扫描 | 纯旋转 10° | 3.47e-16 | **40.4%** |
| | 纯旋转 30° | 1.74e-16 | 14.9% |
| | 纯旋转 45° | 3.47e-16 | **426%** |
| | 纯平移 (2,−1,0.5) | 1.74e-16 | 3.1e-8 |
| | 完整 SE3 45° | 1.74e-16 | 426% |

**读数**：旧 producer 在所有三种重表达下都 ≤5.5e-16（对刚体协变）；**C-2 不是**。
旋转依赖在两个来源上都成立，幅度随扫描变化：room02 最多 **20.1%**，hall01 最多 **426%**。
纯平移只让 room02 动 0.66%、hall01 几乎不动（3.1e-8），所以**主因是轴对齐体素网格与旋转绑定**，
不是平移。完整 SE3 的数值与纯旋转几乎相同，说明两项效应不叠加放大。

**旧读法（保留，标注）**：上一版用 `se3(deg,[2,−1,0.5])`（**同时加平移**）并在
`transport(v0,G)` 之后**按欧氏范数重新单位化**。同一比较下它给出：

| 来源 | 10° | 30° | 45° |
|---|---:|---:|---:|
| room02（C-2，旧读法） | 1.19% | 0.39% | 20.3% |
| hall01（C-2，旧读法） | **103%** | **8.2%** | **495%** |

**这是"含平移 + 再单位化的混合读法"**，不是旋转敏感度：hall01 在 10° 处被读成 103%，
纯旋转下是 40.4%；30° 处被读成 8.2%，纯旋转下是 14.9%。两者方向一致（都有旋转依赖），
但**幅度不能引用旧数字**。旧表与旧百分比保留在 `mixed_protocol_old`，不删除。

**再单位化本身就会改变被比较的量**（`spd_control`，审阅给的精确控制）：

| 步骤 | 值 |
|---|---:|
| 原投影 `v0ᵀΛ0v0`（v0 的欧氏范数 = √6） | 1 |
| 同时搬运 `v` 与 `Λ`，**不**单位化 | **1.0**（差 0.0） |
| 搬运后再单位化 | **1/6**（`‖Ad v0‖² = 6`） |

所以任何旋转控制都必须声明自己用的是哪种读法；本报告的结论只建立在"搬回 anchor、不单位化"上。

**建议：在找到旋转协变的采样方式之前，不要集成 C-2。** 可选方向：按半径壳的确定性抽取
（与朝向无关）、或网格对齐到由扫描自身主方向定义的规范基。这属于新的补丁版本（C-3），本轮不做。

## 2. F2：两个定义，以及"子空间"到底碰的是哪条腿

**定义 A（体素阈值式）**：`m_after` = 特征值 `< 1/σ_tol = 2.0` 的方向数；准入要求 `m_after = 0`。
（2.0 来自门自己的协方差腿 `‖P‖₂ ≤ σ_tol`，不是新参数。）

**定义 B（Loewner 序）**：要求 `Λ_after − κ·Λ_before ⪰ 0` 且 `λ_min(Λ_after) ≥ 2.0`。

### 2.1 上一版的结论对象错了（`06f543a` 审阅）

上一版对 24 个矩阵，各自取**自身**最小特征向量，再比较 `vᵀΛv` 与 `λ_min`，得到 r=1.0、24/24。
**这是同一个数学量的自比较**（`v` 是特征向量时 `vᵀΛv ≡ λ`），与门的 `v` 无关，
**推不出"门的 `v` 就是候选最弱特征向量"**。该段保留为 `tautology_check`，仅作数值自检。

### 2.2 actual gate 控制（取代上一版结论）

直接调用 `evaluate_four_mode_gate`：触发方向固定为 tx，候选 `diag(300,300,300,100,38.8889,38.8889)`，
`Λ_before` 沿该方向取 5，协方差取 `Λ⁻¹`，证据/边界/保持期均满足。

| 量 | 值 |
|---|---:|
| 门的信息腿（沿**固定触发方向**）`after` | **100** |
| 候选自身 `λ_min` | **38.8889** |
| `m_after`（floor 2.0） | 0 |
| 门判决 | **`MODE2_ATOMIC_COMMIT`，accepted** |

**所以门的 `v` 不是候选的最弱特征向量**：最弱方向是 38.8889，门读的是固定方向的 100，并据此准入。
上一版"子空间即标量"的结论由此撤回。

### 2.3 能保留下来的更窄结论

1. `m_after = 0` **等价于 `λ_min(Λ_after) ≥ 1/σ_tol`**，是一个**全谱最小值阈值**。
2. 在同一基且 `P = Λ⁻¹` 精确成立时，
   `λ_min(Λ) ≥ 1/σ_tol ⟺ ‖P‖₂ ≤ σ_tol`——它**恰是门的协方差范数腿**，
   **不是**固定方向的信息腿。（控制里两侧同时成立：38.8889 ≥ 2 且 0.0257 ≤ 0.5。）
3. **Loewner 序**是另一个矩阵层面的条件，与固定方向标量确实不同，值得研究；
   但它**不是"唯一非退化形态"**，本报告不作这种唯一性断言。其判决级比较仍然是 `BLOCKED`（缺 `Λ_after`）。

**判决级比较：`BLOCKED`**——需要 `Λ_after`，归档只有投影标量。定义 B 已冻结，等 `after`。

## 3. F3：证据序列式准入

**冻结定义**：把 paired-benefit 与 holdout 的逐帧证据做成序贯检验（每帧累积对数似然比），
达到上界即准入、达到下界即拒；上/下界由声明的两类错误率算出，不是调出来的。
等待成本 = 从触发到达界的帧数；与 F1 的"一次合取"比较判决差异与等待帧数。

**能独立成立的部分**：等待成本可以用**检测器的逐帧 NIS 流**演示（两条 room02 运行有逐帧数据），
但那测量的是**检测**的停止时间，不是**准入**的；把前者当后者就是偷换对象。

**判决级比较：`BLOCKED`**——归档每条候选只有一个 Wilson 值与一个 holdout 标量，
**没有逐帧证据序列**。要跑 F3，下一趟原生运行需要逐帧 `holdout_nis` 与逐帧 paired 证据
（与 Part 1 的 `candidates_detail.jsonl` 同源，可一并记录）。

## 5. 能推出 / 不能推出

**能推出**：
1. **门的评价方向是固定的触发方向，不是候选最弱特征向量**——actual gate 控制在 `λ_min=38.8889`
   时沿固定方向读 100 并准入。任何"门的 `v` 就是最弱特征向量"的推论都不成立。
2. **`m_after=0` 是全谱最小值阈值；`P=Λ⁻¹` 时它等价于协方差范数腿**，与固定方向信息腿无关。
3. **C-2 补丁不是旋转协变的**：纯旋转重表达下 room02 最多 20.1%、hall01 最多 426%（旧 producer ≤5.5e-16）。
   **这不是"补丁还要调参"，是采样方式选错了**（轴对齐网格）。
4. 三种形态的判决差异**在本归档上不可测**，缺的是逐帧/矩阵级记录，不是计算能力。

**不能推出**：F2/F3 无效；F1 最优；C-2 方向错误（错的是网格，不是"空间采样"这个想法）；
Loewner 是唯一可行的非退化形态。
