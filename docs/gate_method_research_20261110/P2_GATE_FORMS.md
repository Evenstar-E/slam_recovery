## 0. 先说一条会影响 C-2 集成的发现

**C-2 的补丁（体素质心）不是旋转不变的**，而旧 producer 是。

同一场景、绕 z 转不同角度后重算。**两个来源、两种读法**（原件在 `p2_subspace_gate.json` 的
`rotation_control`，脚本可复算）：

| 来源 | 旋转 | 旧 producer（固定方向） | C-2（固定方向） |
|---|---:|---:|---:|
| room02 扫描 | 10° | **1.8e-16** | **1.19e-2** |
| | 30° | 3.7e-16 | 3.87e-3 |
| | 45° | **0** | **2.03e-1** |
| hall01 扫描 | 10° | 3.5e-16 | **1.03** |
| | 30° | 1.7e-16 | 8.16e-2 |
| | 45° | 1.7e-16 | **4.95** |

**读法**：`fixed_direction` 列把 0° 的弱方向用 transport 搬到每个旋转帧再投影，**只让矩阵变**，
这是判断"producer 是否依赖朝向"的那一列；`own_direction` 列混入了方向变化，数值不稳定
（hall 上 622% / 191% / 156%），所以**不要单独引用它**。

结论是定性的、且在两个来源上都成立：**旧 producer 对旋转不变（≤3.7e-16），C-2 不变**。
幅度随扫描与协议变化（room02 最多 20%，hall 最多 495%），因此**记录里不应引用单一百分比**
作为"旋转敏感度"。集成侧（S1）用另一份扫描独立复算得到 24.3%/28.6%/156.4%——方向一致、量级不同，
原因就是来源与读法不同。

**建议：在找到旋转协变的采样方式之前，不要集成 C-2。** 可选方向：按半径壳的确定性抽取
（与朝向无关）、或网格对齐到由扫描自身主方向定义的规范基。这属于新的补丁版本（C-3），本轮不做。

→ 已在 `C2_SPATIAL_PATCH.md` 顶部加同一条警告。

## 1. 三种形态的冻结定义

| | 形态 | 准入条件 | 评价对象 |
|---|---|---|---|
| **F1** | 现合取式（基线） | `after ≥ max(3.0, 2.0·before)` ∧ `holdout ≤ 2.5` ∧ `‖P‖ ≤ 0.5` ∧ paired PASSED ∧ 边界 OK | 单方向标量 + 若干标量腿 |
| **F2** | 可观测子空间 | 见 §2（两个候选定义，其中一个被控制否掉） | 6×6 的谱结构 |
| **F3** | 证据序列式 | 见 §3（序贯检验，达界才准入） | 逐帧证据累积 |

## 2. F2：第一个定义被控制否掉了

**定义 A（体素阈值式）**：`m_after` = 特征值 `< 1/σ_tol = 2.0` 的方向数；准入要求 `m_after = 0`。
（2.0 来自门自己的协方差腿 `‖P‖₂ ≤ σ_tol`，不是新参数；`m` 由此定义，不由分位选。）

**控制结果（24 个真实扫描，C-2 producer）**：

| 指标 | 值 |
|---|---|
| 标量（沿最弱方向）与 `min_eig` 的 Pearson r | **1.0** |
| 两者排序完全相同的位置数 | **24 / 24** |

**这不是巧合**：门的 `v` 就是**最弱特征向量**，所以 `vᵀΛv ≡ λ_min`。
"子空间条件"只是在同一个数上再加一个阈值——**它退化成又一个标量阈值，正是任务要求避免的那件事**。

**定义 B（Loewner 序）**：要求 `Λ_after − κ·Λ_before ⪰ 0` 且 `λ_min(Λ_after) ≥ 2.0`。
这是 6×6 的半正定比较，**不是**任何单方向的标量：两个矩阵可以 `λ_min` 与沿 `v` 的投影都相同，
却在 Loewner 序上不同（在别的方向上分胜负）。

**判决级比较：`BLOCKED`**——需要 `Λ_after`，归档只有投影标量。定义 B 已冻结，等 `after`。

## 3. F3：证据序列式准入

**冻结定义**：把 paired-benefit 与 holdout 的逐帧证据做成序贯检验（每帧累积对数似然比），
达到上界即准入、达到下界即拒；上/下界由声明的两类错误率算出，不是调出来的。
等待成本 = 从触发到达界的帧数；与 F1 的"一次合取"比较判决差异与等待帧数。

**能独立成立的部分**：等待成本可以用**检测器的逐帧 NIS 流**演示（两条 room02 运行有逐帧数据），
但那测量的是**检测**的停止时间，不是**准入**的；把前者当后者就是偷换对象。

**判决级比较：`BLOCKED`**——归档每条候选只有一个 Wilson 值与一个 holdout 标量，
**没有逐帧证据序列**。要跑 F3，下一趟原生运行需要逐帧 `holdout_nis` 与逐帧 paired 证据
（与 Part 1 的 `candidates_detail.jsonl` 同源，可一并记录）。

## 5. 能推出 / 不能推出

**能推出**：
1. **"可观测子空间门控"最自然的写法会退化成现有标量**——因为门的评价方向就是最弱特征向量。
   要真正不同于标量，必须用矩阵层面的比较（Loewner 序）；这是 F2 唯一没有自我否定的形态。
2. **C-2 补丁引入最多 19% 的旋转依赖**，在这一点上不如旧 producer（3.7e-16）。
   **这不是"补丁还要调参"，是采样方式选错了**（轴对齐网格）。
3. 三种形态的判决差异**在本归档上不可测**，缺的是逐帧/矩阵级记录，不是计算能力。

**不能推出**：F2/F3 无效；F1 最优；C-2 方向错误（错的是网格，不是"空间采样"这个想法）。
