## 0. 共同边界

- **0 次宿主运行**；全部离线/归档重放。
- **独立质量标签不存在**：归档没有"候选修得好不好"的独立判据，所以任何"多接纳/少接纳"都只能是
  **UNKNOWN**，不能写成收益或损害。
- 每个方案只跑预先冻结的版本；失败不调参再跑（B-v2 之后按裁决不再开 B-v3）。
- 三条方案回答的是三个不同问题，**不能合并成一句"都不行"**。

## 1. A：删除信息腿

| 项 | 结果 |
|---|---|
| 数据 | 18 条归档候选（16 room02 + 2 hall），两个候选来源 |
| 重放自检 | 17/18 由字段逐条复现；1 条（`3073038`）旧判据下无归档结果 → `BLOCKED` |
| 现门 vs A | 判决**翻转 0 条** |
| 未决 | **4 条 `BLOCKED`**：都缺 `‖P_after‖₂`（`3073038` + `3036955 / 3057611 / 3059939`） |

**能推出**：在本人口上，删信息腿不改变任何一条**可判定**的判决；`3073038` 从"信息腿拒绝"变成"未知"。
**不能推出**：信息腿无价值；协方差腿足够；A 方案无效。唯一能区分 A 与现门的样本类型
（仅信息腿拒、其余腿**已测**通过）在本归档里不存在。

## 2. B：健康前缀条件化（两版）

### B-v1 冻结前缀

| 项 | 结果 |
|---|---|
| 首次报警 | −16.843 s → **−8.217 s**（提前量减半） |
| 盲区 | **5.74 s** |
| onset 前可判定帧 / 其中被标出 | 168 → 126 / **42** |
| 机制 | 首次 SUSPECT 归一化 **2.11**（刚过 2.074），随后隔离由 **CUSUM** 触发（1.96 / 4.90） |
| 根因 | **冻结尺度跟不上地图增长**（前缀中位 13.27 vs 51–100 关键帧档 18.0） |

**能推出**：冻结前缀能推迟报警，但**在原理上**跟不上一张长大的地图。
**不能推出**：B 这一类方法无效——B 的两种更新方式只测了这一种。

### B-v2 滚动尺度（不过滤）

| 项 | 结果 |
|---|---|
| 首次报警 | **+4.317 s**（进入注入窗内） |
| **故障吸收比** | **49.9×**（尺度 11.5 → 831 → 959） |
| 窗内覆盖 | **0.291**（三段 0.273 / 0.470 / 0.125） |
| 附加代价 | 故障结束（≈+14 s）后尺度塌回 3.5，**+19.66 s 对"恢复"又报一次** |

**能推出**：未过滤的滚动健康估计会被它要检测的东西带偏——**在故障持续期间自我关闭**。
这条是 B 的核心风险，已被实际数据证明，不是假设。
**不能推出**：带回污染识别的滚动版本也失败（那是 B-v3，按裁决未做）。

**读法提醒（写进结论用）**：B-v2 的"+4.3 s 报警"**不能当收益**，它是用"故障期间回到 HEALTHY"换来的。
决定 B 可用性的是 **49.9× 的吸收比**与 **0.291** 的窗内覆盖，不是首次报警时刻。

## 3. C：FIM 量纲/可观测方向重定义（数学正常控制）

| 控制 | 结果 |
|---|---|
| 坐标重表达 | **PASS**，相对差 1.7e-16 |
| 点数中立性 | **FAIL**：同一扫描 40.911（stride 1200）/ 32.225（全量）/ 30.489（全量+复制） |
| 采样密度 | **FAIL**：半采样的投影比 1.054–1.102，跨度 0.048 |
| 物理尺度 | 平移块**不随缩放变化**（59.259）；旋转块按 s² |
| 方向选择 | `own_min` 35.789 ≠ 固定方向投影 40.911 |

**能推出**：C 声称的"缺 per-point 归一"不成立（已是 mean）；坐标维没有缺陷（1.7e-16）；
但**采样与邻域定义**有真实缺陷——输入点数改变结果 **21%**，来源是 stride 子采样与按点数取邻域。
**不能推出**：需要新的 FIM 量纲；也**不能**用任何重定义消掉剩下的 36.5× 跨场景变化——那是可观测性本身。

**C 的可修形态是具体的**：评估样本改空间（voxel）采样（`support_reference()` 已这么做）、邻域改按半径。
这是采样定义修改，不是量纲创新。实际候选上的效应 **`BLOCKED`**（缺带点云的候选流）。

## 4. 三条方案各自回答了什么

| | 回答的问题 | 结论类型 | 对用户的意义 |
|---|---|---|---|
| **A** | 信息腿有独立增量价值吗？ | **本人口上无增量，0 翻转，4 未决** | 删掉它在本数据上不会多放行任何东西；也没证据说它有害 |
| **B** | 用健康历史条件化尺度能救检测吗？ | **冻结跟不上；滚动会吸收故障** | 问题不在窗口长度，在"污染样本如何被识别" |
| **C** | 现在这个信息量统计量有定义缺陷吗？ | **坐标没有；采样/邻域有，且可分离** | 修采样定义即可，不需要新量纲；跨场景差异是物理的 |

## 5. 不能由本报告推出的

- 不能推出"A/B/C 都不行"——三者失败的环节不同：A 是**样本缺失**，B 是**形式缺陷**，C 是**缺陷定位**（并给出了可修形态）。
- 不能推出任何门改法会让候选通过：18 条候选里 4 条卡在未归档的协方差上，其余 14 条在信息腿之前就被别的腿拒了。
- 不能推出跨输入泛化：room02 单 bag 家族 + hall 两趟，且 hall 两趟因报警提前不构成独立确认。
- 不能推出"检测不可用"的总判断：本报告只测了 NIS 分支与信息腿，几何分支未重放（归档无 FIM）。

## 6. 用户要选的是

1. **是否继续投入 C 的采样定义修复**（最小、最接近"可部署"：voxel 采样 + 半径邻域，不碰门限）；
2. **A 是否保留**——本人口上它不影响判决，但也没有证据支持删除；决定权不在数据；
3. **B 是否在"污染识别"有解之前搁置**——B-v2 证明无过滤的滚动会自毁，B-v1 证明冻结跟不上；
   两者合起来说明 B 缺的不是参数，是一套三态（可信/污染/未知）支持判据，那已属 C 邻域。
