# C-1 实验：FIM 量纲/可观测方向的正常控制（2026-11-10）

研究分支 `exp/gate-method-research`，不改生产门。本文只报 C 的数学正常控制，**未进入实际候选评价**。

## 1. 定义（运行前写死）

```
P(v, L) = v^T L v,   L = mean_i(J_i^T J_i) / sigma^2,   J_i = [(p_i x n_i)^T, n_i^T]
```

- `v`：**固定触发方向**，不是逐帧自选弱方向；
- 单位：平移块 1/m²，旋转块 1/rad²；
- 切空间 `[rot(3), trans(3)]`，在 A7 的固定 anchor body 基下评价；
- FIM 的 `sigma = 0.075`（与 NIS 的 σ 无关）。

**先驳三条前提**（审阅侧已更正，这里作为控制复现，不重复主张）：
现 FIM 已是 `mean(JᵀJ)/σ²`，不是点数总和；逐帧自弱向最大值不是固定方向投影的上限；
`weak_dir_info ≡ min_eig_trans` 只在纯平移分支成立。

## 3. 五项控制

### C1 点数中立性 —— **不成立（`NOT_COUNT_NEUTRAL`）**

| 评估方式 | 投影 |
|---|---:|
| 默认（stride 子采样到 1200 点） | **40.911** |
| 全部 8000 点 | 32.225（相对默认 **0.788**） |
| 全量 + 点云复制一份（16000 点） | 30.489（相对全量 **0.946**） |

同一物理扫描，仅因为交给 producer 的点数不同，投影差 **21%**；在同一评估方式下复制点云，再差 **5.4%**。

原因分两层，且**都不在"缺 1/N"**：
1. producer 的 `pts[::step][:max_eval_points]` 让 `step` **是 N 的函数**（8000→6，16000→13），所以采样点本身随 N 变；
2. k 近邻**按点数取**，复制点会引入零距离邻居，法向随之改变。

### C2 采样密度 —— 同源

随机保留一半（5 个种子）的投影比：1.099 / 1.102 / 1.084 / 1.054 / 1.098，跨度 0.048。
同样来自 stride 与 kNN，不是尺度缺陷。

### C3 坐标重表达 —— **PASS**

把点云整体转 30°、平移 (2, −1, 0.5)，重算 FIM 并把 `v` 搬到同一基：
`40.91107484012684` vs `40.91107484012683`，相对差 **1.7e-16**。
**producer 的 Jacobian 与 transport 约定是一致的**；A7 之后，坐标这一维没有缺陷可修。

### C4 物理尺度 —— 平移块与尺度无关

| 场景缩放 | 平移块平均特征值 | 旋转块平均特征值 |
|---:|---:|---:|
| ×0.5 | **59.259** | 763.4 |
| ×1.0 | **59.259** | 3053.7 |
| ×2.0 | **59.259** | 12214.7 |

法向看不见均匀缩放，所以**平移块对场景尺度不变**；旋转块按 s² 缩放。
本帧的弱方向是平移主导，因此投影不随缩放变化。

**这条改变了对 `tau_abs_min` 的读法**：作用在平移主导的弱方向上时，常量 floor 是一个
**法向角度多样性**的陈述，**不是**距离尺度陈述。

### C5 方向选择 —— 两个不同的量

本帧 `own_min_6d = 35.789`，沿固定触发方向的投影 `40.911`。两者不可互相界定——
这正是审阅侧"逐帧自弱向最大值不是固定方向投影上限"的更正月，以控制形式复现。

## 4. 结论：C 声称的缺陷在哪、不在哪

| C 的候选主张 | 判定 | 依据 |
|---|---|---|
| 现 FIM 缺 per-point 归一 | **不成立** | 已是 mean；复制点云不改变 1/N 因子（那 5.4% 来自 kNN，不是归一） |
| 需要坐标/量纲重定义才能跨坐标系比较 | **不成立** | C3 相对差 1.7e-16 |
| 采样/尺度会污染统计量 | **部分成立，且可分离** | C1/C2：**输入点数**改变结果 21%，来源是 stride 子采样与按点数取邻域 |

**因此 C 的真实缺陷是一个"采样与邻域定义"问题，不是一个"FIM 量纲"问题。**
可修的形态是具体的：评估样本改成**空间（voxel）采样**（项目里 `support_reference()` 已经这么做），
邻域改成**按半径**而不是按点数。这不是新量纲，也不需要再除一次点数。

**不能修的**：剩下的跨场景变化（36.5× 那一段）是**场景几何**本身。任何重定义都无法把
"这批点云的平面法向分布"变得与另一批相同——那正是可观测性，不是伪影。
