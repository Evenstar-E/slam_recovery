# A 方案实验：删除信息腿（2026-11-10）

研究分支 `exp/gate-method-research`，不改生产门。本文只报 A-1 这一版。

## 1. 定义、统计量、单位与固定切空间

**被判对象**：门在 Mode 2 前的信息腿，三个条件：

```
after >= tau_abs_min = 3.0
after >= tau_info_kappa * before = 2.0 * before
gain = after - before > 0
```

`after = v_triggerᵀ Λ_after v_trigger`，`before = v_triggerᵀ Λ_before v_trigger`，
`v_trigger` 是**触发帧固定方向**（不是逐帧重选），`Λ` 为 `mean(JᵀJ)/σ²`（已含点数归一，
σ=0.075，与 NIS 的 σ 无关），单位是**信息**（m⁻²），切空间 `[rot(3), trans(3)]`，
评价基固定在触发帧 body anchor（A7 的固定基）。

**A 的定义（执行前已固定）**：删除上面三条件，保留 Mode 1 时长判据、paired evidence、
holdout NIS、协方差谱范数、段边界连续性。**不是删全部准入。** 不改任何数值。

**文献**（仅用于界定"信息/可观测性判据"的通常用法，本项目这条判据本身来自项目内方法，不是文献结论）：

- J. Zhang, M. Kaess, S. Singh, "On Degeneracy of Optimization-based State Estimation Problems," ICRA 2016 — 用信息矩阵谱判可观测性与退化方向；说明"弱方向信息"是有物理含义的量，不是任意分数。
- Y. Bar-Shalom, X.-R. Li, T. Kirubarajan, *Estimation with Applications to Tracking and Navigation*, Wiley, 2001 — NIS 的一致性检验；用于界定 holdout/NIS 与信息量是两类不同的证据。

两者都不支持也不反对"删除信息腿"；它们只说明这条腿在被检验的对象里对应什么。

## 2. 数据与方法

- **同一候选流**：18 条归档候选（`/tmp/fl_native_*/candidates.jsonl`），两个来源
  （`host_poses` 与 `icp_reregistration`），room02 16 条 + hall 2 条。
- **重放器**（`a1_leg_attribution.py`）按 `core.py` 的腿顺序从归档字段重建判决：
  边界 → paired evidence → 有限状态 → holdout → Mode 2 合取。
- **自检**：先用**归档当时**的判据（`after >= 25`）重放，要求逐条对上 18 条的
  `mode`/`refusal_reason`。**17/18 由字段重放对上**。
  第 18 条 `3073038` 的归档理由 `Insufficient verified info` 是**新判据**（ratio 1.0117 < 2）下的拒绝，
  旧判据下它没有归档结果，因此旧判据重放 = **`BLOCKED`**，不强行对齐。
  （一处仍需由归档反推的未知量：`reentry_elapsed_s` 未归档，理由本身证明 elapsed 信封放行了跳变，
  否则证据腿会先拒并换一条理由。）
- **0 次宿主运行**；每候选的 `‖P_after‖₂` 未归档处一律 `BLOCKED`，不填默认值、不借上一帧、不合成。
- **一个记录陷阱**：`3075620` 等行的 `weak_dir_info_after = 0.0` 来自当时**空候选**的旧记录
  （空候选没有位姿），不是"实测信息为零"。S1 已在 `915213f` 修成空候选单列并记 `null`；
  本分析的 `0.0` 只用于识别非有限腿，不当实测值使用。

## 3. 结果

| 判决腿 | 现冻结门 | A（删信息腿） |
|---|---:|---:|
| 段边界 | 7 | 7 |
| paired evidence FAILED / MISSING | 3 / 1 | 3 / 1 |
| 非有限状态 | 3 | 3 |
| 信息腿 | **1** | — |
| 到 Mode 2 合取、缺 `‖P_after‖₂` → `BLOCKED` | 3 | **4** |
| **判决翻转** | — | **0** |

**A 没有翻转任何一条可判定的判决。** 它做的唯一一件事，是把 `3073038`
（before 45.456 → after 45.989，ratio 1.0117 < 2.0）从"信息腿拒绝"变成"`BLOCKED`"：
删掉信息腿后它到达 Mode 2 合取，是否被接纳取决于**未归档的** `‖P_after‖₂`。
**`BLOCKED` 不是接纳**——所以翻转数仍是 0，但也不能把这条写成"仍然被拒"。

另外 3 条（`3036955` / `3057611` / `3059939`）在**现判据**下信息腿已通过
（after 4.03–4.66、ratio 3.66–4.23），它们与 A 无关；它们能否到 Mode 2 同样取决于未归档的
`‖P_after‖₂`，现门与 A 在这一点上同样 `BLOCKED`。

**因此本人口上总计 4 条 `BLOCKED`（都缺 `‖P_after‖₂`），0 条翻转。**

## 4. 逐项结论

| 问题 | 结论 | 依据 |
|---|---|---|
| 信息腿在本人口上有独立增量价值吗？ | **测不出增量：0 条翻转** | 17/18 字段重放自检通过后，现门与 A 的可判定判决逐条相同 |
| 删除后会多放行有益、有害还是 UNKNOWN？ | **没有多放行**（翻转 0）；1 条转入未知 | 同上；且归档无独立质量标签 |
| 全 P 谱范数在当前模型/正则/基下是否足以覆盖需要的约束？ | **本数据不能回答** | **4 条候选都缺 `‖P_after‖₂`**，其中 3 条正是现判据下信息腿已通过的 |
| 是否有受 producer 错误影响的判决？ | 不确定，**不主张门有效性 PASS** | 空候选的 `0.0` 记录、协方差未归档都属记录缺口 |

## 5. 这个负结论能推出什么、不能推出什么

**能推出**：在这 18 条候选上，删掉信息腿**不改变任何一条可判定的判决**（0 翻转），
只把 1 条从"拒绝"变成"未知"。所以"删掉它能多接纳候选"这一设想在本人口上**没有支持**；
此前"删掉会放行有益候选"的直觉来自 9 条 ratio 3.66–4.26 的候选，而它们在**现判据下本来就
已经通过信息腿**，挡住它们的是别的东西（或未归档的协方差），删信息腿对它们不起作用。

**不能推出**：信息腿在其他人口上没有价值；协方差腿总是足够；A 方案无效。
18 条里没有一条是"仅信息腿拒、其余全过且协方差**已测**通过"的样本 —— 那样的样本在本归档里
**不存在**，而它正是唯一能区分 A 与现门的样本类型。`3073038` 最接近，但它缺协方差，
所以它是 `BLOCKED`，不是证据。
