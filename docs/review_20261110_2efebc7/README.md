## 4. 重放的两个实际适用边界

1. **不是完整真实检测路径。**replay只选`nis_reference == node_map`且有限的帧；真实驱动还要求`_frame_has_reference_support`通过（否则UNAVAILABLE），并计算实际FIM几何分支。diagnosis-off summary并未提供每帧真实support/几何判据供完整重放；因此“node_map过滤等同warm-up”“窗前完全不报警”只对当前NIS简化重放有效。阶段一同trigger timestamp是一个局部check，不证明其他sigma或所有阶段一致；精确归档回放可核确定性，但不要求随机宿主逐次同时间。
2. **检测反馈改变后续输入状态。**detection-off期间所有帧用于继续长图，NIS序列来自该不断长大的参考。on模式第一次触发后隔离冻结/撤销参考，后续NIS与候选不会继续沿同序列。首次触发前可作有限探索比较，之后事件持续性/尾部与接回/E2不能用这批离线重放代替在线运行。

因此“几何分支若报警只会加强不可用”也不能作一般定论：真实故障时几何告警可能增加有益检测；须区分故障前误报与故障内告警。保持范围而非新增FIM日志/重放框架，下一真实运行沿已有状态/支持证据报告即可。
