## 二、`5262f86`：修得对，代价也报得对

### 2.1 缺陷是真的

旧选择器按**平面内点数**挑假设。真实室内扫描里地板赢：地板 29 301 内点 vs 袋面 21 421，于是剥掉的是地板，袋子留下——只删了 54–57%，约 **17 000 个袋点存活**。

新选择器改按**"该假设能解释多少回波属于近场薄板"**打分（`point_mixture_repairer.py:84-90`），并用选中的 sheet 而非原始 inlier 作为污染集（`:96-101`）。

### 2.2 效果与代价（manifest 直读）

| 指标 | 数值 |
|---|---|
| 12 帧平均剥离率 | **0.8884** |
| 袋点存活总数（12 帧） | **88** / 约 547 k |
| 真实背景点误删总数 | **69** / 约 65 k |
| 去注入 room_02 近墙扫描误剥离 | **58/76 = 76.3%**（旧 5/76 = 6.58%） |
| hall_02 近墙 | 0/62 |

`p10_hard_negative_and_rot_ate_benchmark.json` 里 `naive_geometry_only_ransac_false_strip_rate = 0.7632`，与提交信息一致。论文与研究文档都已写入 76.3%，没有藏。

### 2.3 一个被提交信息轻描淡写的事实

12 帧真实注入扫描的 `geometrically_repairable` **全部为 False**，`min_bg_eigenvalue` 在 **0.90–7.99** 之间，远低于门限 15。

也就是说：**在真实塑料袋数据上，点级修复从未单独成立。** 剥离 88% 之后剩下的 12% 不足以支撑 6-DoF 位姿。实际恢复全部来自双端锚定的桥接，而不是"点云混合修复"。

这不否定方法，但它改变了论文的表述：**点级剥离是预处理，不是修复器。** 现在论文若仍把它写成一条独立的修复路径，与实测不符。

### 2.4 我的独立探针复现了误剥离

在合成近墙扫描上（墙 55%、地板 35%、背景 10%，墙在正前方 1.5 m）：

```
kept fraction 0.4324   contam_ratio 0.5676   min_eig 0.69   repairable False
wall kept 0.0000   floor kept 0.9497   bg kept 1.0000
```

**真实墙体 100% 被删。** 代价被 `repairable=False` 兜住了（不会拿这些点去修复），但这也印证了开发侧的判断：**滤波器无法区分 1–3 m 处的袋子和 1–3 m 处的墙**，唯一能区分的仍是时间维度（世界系静止 vs 体坐标系静止）。

## 三、P1：仿真与真实注入的遮挡模型不同，0% 不能迁移

这一条是本轮最重要的发现。

| | 仿真 S1/S2 | 真实注入（M2DGR bag） |
|---|---|---|
| 遮挡建模 | **移除**该方位扇区：`body_cloud = body_cloud[~occluded]` | **替换**为近场薄板：`pts[is_bag,:3] = dirs * d_sheet`，强度 200 |
| 扫描里有没有假点 | **没有** | **有，约占 88%** |
| 提交原始扫描会怎样 | 只是少一片，不会造假墙 | **把假墙写进地图** |

而在线节点的地图重建是：

```python
# transaction_manager_node.py:99  _sync_spatial_map_with_trusted_poses
pts_b = self.scan_buffer_body[kf_id][:, :3]   # 原始扫描，未过滤
```

`scan_buffer_body` 全文只有一处写入（`step_frame`，原始点云），**节点从未调用 `filter_self_consistent_near_field_contaminants`**。

因此：

- 在**移除模型**下，隔离后再提交原始扫描，污染率确实是 0（因为没有假点）——B4 = B6 = 0% 是这个模型的产物。
- 在**替换模型**下，隔离只保证"退化期间不写"；一旦桥接修复通过验证并提交，`_sync_spatial_map_with_trusted_poses` 会把**带假墙的原始扫描**按修复位姿重新投影进地图。

**结论：「验证后准入的污染率为 0%」目前只在移除模型下成立，不能外推到真实塑料袋。** 新摘要把它写成 "both report zero contamination" 而没有标注模型前提，审稿人若对照 `injectors.py` 会发现。

修法（二选一）：

1. 提交前用过滤后的点云替换 `scan_buffer_body` 中对应关键帧，并在 manifest 记录每帧剥离率与存活点数；
2. 或者明确声明该结论只适用于移除模型，并在真实注入上改报"轨迹误差 + 未提交帧数"，不报地图污染率。
