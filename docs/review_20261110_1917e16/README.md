## 2. 新证据仍不支持改门理由中的强结论

### 旧完整gate“把好坏判反”仍未证明

旧门还有`gain>0`，40.23→34.47已被拒，早期原stream也是Mode3；新代码注释、测试docstring和预注册仍称旧门接纳该候选，这与已核旧证据不符。新离线before复现不改变这个事实。onset/信息增加不是独立有益标签。

新`test_tau_info_criterion`只借用实测before/after标量，自己设`P=.02I`、holdout=.1、Wilson=.9、jump=.02。其Mode2证明**满足其他腿的合成candidate**能过新门，不证明原run044830Z或051744Z在新门会接纳；原posterior cov未归档，反事实仍UNKNOWN。这不要求再造数据矩阵，下一实际交付如实标范围即可。

### 3.088是换采样、换弱方向的一帧值，不是整类候选的排除边界

`fim_summary`每次重求weak direction；不同pitch的二次型方向已改变。onset的0.3m方向含旋转分量约.472，不是“恒等于最小平移特征值”的纯平移方向；FIM实现会按耦合6DoF分支把返回的`min_t`覆盖为6D最小特征值。0.3m得到3.08784可以记录为该采样方法的一帧描述值，不能直接认定是**旧触发方向上的候选after下界**。实际candidate又在旧触发方向投影并对多帧FIM取平均，统计量不同。

“floor>3.09会排除整个onset类”有现成正常控制反例：同新fixture before1.1019/after4.628，只在review局部用floor3.5（生产不改），仍Mode2。门比的是after，不是另采样的before3.088。故3.0仍是一个开发方法选择，不是实测证明的通用最低值；不建议再扫描floor。

1.0m/12点的`.001`来自FIM `n<k_neighbors+1`返回`.001I`的fallback，并非测出的几何信息下限。已用现FIM12点控制核过；缺足够支持可诚实记不可评价，不用“几何消失”推导数值阈值。`.038–.050`缩放表已标非测量，这点保留；ICP残差仍不等FIM物理噪声，不能由表证明所有绝对门都无效。
