## 确认比较前的三个最小评价修正

### 1. 四臂交集作主表会删除全部恢复人口

位置：`B10_PREREGISTRATION.md:23,31,58`。Q仅保留onset前帧，因此N∩Q∩U∩G必然包含不了隔离后恢复帧。

本机纯集合反例：N=U={1,2,3,4,5,6}；Q={1,2}；G={1,2,3,4}。共同集={1,2}；G比Q恢复{3,4}，但这两帧在主表中均消失。即使G在这些恢复帧构出了假地图，也可在健康prefix主表上看起来不劣。另列missing数不能恢复被排除的几何质量。

**最低解除：**复用既有固定scan/input人口、独立可见参考与ROI，对各臂实际完整地图报覆盖、unsupported、新增正确/错误和正常损失；逐帧缺失仍保留。共同时间轨迹误差另作条件性副表。N/U也不能预写“全部有”，实际宿主缺输出/候选未生成照实计缺失；不得以输出交集重新定义全人口。

### 2. decision摘要不足以重建无门控臂和独立评候选

位置：`candidate_stream_schema.md:8-27,34-39`。只有committed/deferred keys、准入数值和first-trigger pose，没有全部候选修复SE(3)或其产物入口、使用的测量来源。某候选有38..42，G只接38..40：仅此JSONL无法知道41/42的候选位姿，也无法复算U，更无法独立判断拒绝是否损失有益修复。

**最低解除：**decision JSONL可保持轻量，引用已经产出的candidate artifact/manifest，保留**门过滤之前的全部**候选pose keys→SE(3)、相应scan/实际修复测量来源及固定run/parent身份；包括被拒/待定候选，不仅最终trusted地图。调用点已有值序列化即可，不新增估计器或修复计算。另保留system pending/输入人口来源，不能从候选列出的keys推断全部待处理帧。

同候选流的离线策略重放可用于B5门的受控增量，但不能冒充四个原生闭环：接纳会改变未来宿主状态/地图/候选流。明确控制重放还是各策略真实宿主执行；后续真实闭环的反馈与成本不能由一条G运行复制出来。

### 3. 文档说“写死”，实际判定界限仍未给值

位置：`B10_PREREGISTRATION.md:54-60`。有益损失界限、coverage/unsupported非劣界限、独立有害/有益/未知标签规则及单位/评价范围没有固定实值或指向已有定义。现文件冻结的是方向，不能称完整确认性判定已冻结。

**最低解除：**复用已有科学门与评价定义，缺的确认性效应界限在确认运行前由开发侧明确；未声明记UNDECLARED，先运行则标探索性，不能看结果后补界限再叫预注册。审阅侧不擅自设更严门槛，也不放宽原门；原生接线不依赖设计全部新界限。
