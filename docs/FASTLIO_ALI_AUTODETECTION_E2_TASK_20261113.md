## 4. 最小技术路径与证据条件

### 4.1 原生起点与输入归宿（S1/S2）

- `re_slam`是重置，不是历史restore；不得复制FAST-LIVO2 octree/replay名称来充FAST-LIO能力。核本host的状态、ESKF协方差、velocity/bias/gravity/外参、IMU积分/deskew必要缓存、时间游标和ikdtree/局部地图，恢复到同一逻辑时刻。只保存pose或state/map不含实际必要依赖不能称完整cp。
- cp必须实际成功、有效且不晚于受支持隔离起点；先核ACK成功/valid，再解释timestamp。复用已有FAIL valid0负时间戳误标反例做最小修正，不扩异常矩阵。历史候选必须真实选择并带相应IMU/输入历史，不仅列早戳。
- 若当前只能健康prefix原生重跑，可明确交 **offline measurement-filtered native rerun** 作为真实重估阶段，不当在线局部回退/完整cp已解决；S2交剩余具体接口，不静默降完成标准。
- 过滤保存整条原生点记录与ring/time等字段，IMU按原消息透传、保持精确时间/scan身份。实际repairer不读注入mask/干净背景/GT，不造未观测几何；正常点误删要测。清缓存后重处理不得仍使用污染云构图。
- 所有隔离、pending、已消费历史和健康suffix有明确归宿。accepted、rejected、timeout、无法回溯分别说明；restore+resume仅放hold不算追赶。保完整消息分母、缺失/重复/未决，不用未来输出替历史catch-up。
- E2迟检跨E1提交时，支持就撤销相关状态/map贡献并重算；不支持就明确拒绝回溯范围、记录未恢复及后继归宿。安全拒绝可以正确执行，但不算成功恢复。

### 4.2 ALI-H真实证据与有限自动入口（S3/S1/S2）

- 复用[ALI-H v1设计](ADAPTIVE_LOW_INFORMATION_HEALTH_V1_20261112.md)与已验`ali_h_v1.py`/SE(3)Log工具，不重写reader/重复旧数学。当前方法是EMPTY/LOW/SUPPORTED上下文和NORMAL_CONSISTENT/SUSPECT/UNKNOWN健康观察；scope为RELATIVE_MOTION_ONLY/MAP_AND_MOTION/NONE。
- FAST-LIO本次原生导出真实同update IMU传播prior和LiDAR posterior、真实M/T及有效约束/点归属。旧FAST-LIVO2 v11同行资格仅数学/来源参考，**不贴成本host run的真实通道证据**。缺失/carried/eff0/越支持集不得作NORMAL支持；raw header跨度包含不等完整点成员证明。
- Ppre/Ppost不直接当Log差值协方差，不能相加或换frame标签冒残差Sigma；未有合法Sigma用已声明单位权，禁止卡方/健康概率主张。M/T同源、I共享历史，不能算独立传感器一致即地图正确。
- 沿首版0.5s非重叠块、各通道/上下文独立正常开发前缀至少20有效块、经验序`u=(1+count(b<=s))/(n+1)`、相邻有证据块`u≥.95`报警、`u≤.80`兼容；missing断dwell/保last suspect。规则在确认前冻结，不为过门扫新数值。
- NORMAL需I加M或T；I+T仅相对运动scope，不直接授权地图提交。UNKNOWN不默认trusted、不填0解除报警；保历史异常且明确隔离/pending代价。支持范围不足只能shadow/弃权，不能在线强制二分。
- 同source/config/input、同帧/块人口对比旧检测与ALI-H，标签仅离线。既有声明自注入标签只可评价其故障类；自然正常段需独立依据，不能无注入即正常。新校准材料无法独立确认时标BLOCKED/NOT_EVALUABLE，不以换字母路线或全部工程停工替获取具体证据。
