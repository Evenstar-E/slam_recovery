## 2. 修法 A 的直接证据

`pgo.log` 出现 **819 次** `similar-closure: skipping sleeping map N with no keyframes`
（先 map 1，其后反复 map 0）。这正是 v2 触发断言的同一条件——空休眠地图。
`alaserPGO` **全程存活**：7921 条 `/aft_pgo_odom`，最后一条记录在墙钟 958.5 s（录制终点），
无 `died`/`Assertion`。

> 结论边界：这证明「空休眠地图路径在带 hold 的运行里确实会被走到，守卫把它拦住了」；
> 但它不等于证明了 v2 那次崩溃的根因就是这一条（v2 无栈回溯）。
