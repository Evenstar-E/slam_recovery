## 核验后应修的问题

### 1. 视觉贡献结论不成立

p11 manifest 的 findings 第 58 行把 clean noimg 的近似相等外推到退化场景。camera-only 近似 clean 也不能证明视觉被禁用或无效：LiDAR 可在 clean 条件下掩盖视觉退化，且退化图像仍可能提供有效信息。hall_01 的 both 窗口 RMSE 0.6752 比 LiDAR-only 0.5868 高约 15%，值得保留，不能由全程 ATE 近似相等抹去。

下一次应补相同 LiDAR 注入下视觉开/关对照、每帧视觉选点数、有效光度残差数、更新前后状态变化，并核对标定。不要直接比较 img_point_cov 与 dept_err 的数值作为相对权重：量纲、残差空间及归一化不同。

### 2. 视觉参数可静默失效

prepare_m2dgr_for_fastlivo.py:163-168 在任一 visual 时间界缺失时始终不注入。用户指定 --visual-gain / --visual-blur 而漏一个界，程序仍成功写出 clean 图像。写输出前验证成对时间界、顺序、与转换窗重叠，并保存注入图像/点云计数到 manifest。

### 3. 对齐协议元数据有歧义

p11 顶层 prefix_poses=170 是 room_02 某臂的值，不应作为全部运行共用元数据。hall_01 四臂匹配数 549/553/562/558，按 evaluator 的 int(20% n) 应分别为 109/110/112/111。每臂落实际 prefix 数、时间界、关联支持；比较时使用预先固定的健康时间窗和共同评测支持。

### 4. 噪声跨帧重复

converter 每帧以 seed=42 调用 exposure 注入，生成重复的底层随机场。本机确认相同图像连续调用结果逐字节相同。需要持续 RNG 或以固定运行 seed 派生逐帧 seed，区分模拟 shot/read noise 与有意固定图案噪声。

### 5. 模糊新引入 OpenCV 依赖

JPEG 解码支持 Pillow 回退，但 motion blur 在 injectors.py:162 无条件 import cv2；无 OpenCV 环境到第一张退化图像才失败、留下半成品。预检查依赖并清楚报错，或实现回退。核缓存属于可选优化，不是本轮阻断项。

## 两个仍然开放的基础问题

1. transaction_manager_node.py:345-351 用候选位姿生成参考，再在 :383 传给配对评分；全部可配对扫描参与评分。候选派生参考与评分集存在重叠，独立证据承诺不成立。自贴反例测试不等于实际节点路径已修；需修入口并加入口级回归。不能声称每个重叠帧必然改善或给固定偏差比例，影响量需重跑测量。
2. LOOP_OUTLIER 当前 repairer（loop_and_sync_repairer.py:20-86）在前端/PGO 的平移增量间加权混合，num_revoked 是低权重增量数，不是宿主删除的回环因子数；未传入因子 ID，也未调用宿主优化器重优化。所谓 odd-index holdout 仍使用参与权重拟合的增量，不是严格独立留出。正式 HILTI 实验必须在真实位姿图边上测试，否则只能叫轨迹后处理。

## 对此前审阅措辞的校正

- clean 视觉开/关指标相近，只证明该指标下边际收益小，不能证明视觉模块惰性。
- 0.35 m 与 4.30 m 是重要的比较混杂项，但“近距离一定更温和”“体素自动抹掉薄板”“IMU 足以撑住 20 s”都没有日志证据，不能作为已确定原因。
- 验证降低错误提交风险，不构成任意宿主绝不变差的保证；相关扫描下 Wilson 的名义置信度也需重新审视。
- 约 10.3k on-surface 已提交体素是准入非空的证据，不是参考表面覆盖率，也未证明四臂在相同观测条件下的净覆盖增量。
- 真实点云过滤、修复位姿、地图重建必须逐段验证接口闭合，不能由离线轨迹提升直接推导宿主地图已修复。

## 论文实验矩阵：已有与不足

已有：多序列、多宿主归档；几何退化、测量污染、时间偏移、低光/模糊、部分复合退化；B0–B6 宏消融；部分误干预对照与失败候选；受控体素事务和回滚测试。

不足：真实错误回环因子闭环；合法回环保护；单宿主同输入的四臂地图对照；地图准确度+完整度；独立评分参考及相关性处理；误提交/漏恢复及无候选分母；五宿主中 FAST-LIVO2 的实际修复臂；1× 真实宿主闭环与排队/时延；细粒度组件消融；弱污染/慢增慢减恢复边界。

有可发展的创新主张：把检测、故障起点回溯、候选重处理、可撤销地图更新与独立验收连成一个宿主适配的恢复过程。尚未证明任意传感器/任意宿主即插即用；事务、回滚、鲁棒后端、主动重观测各自都有先例，新颖性须以接口、非平凡决策及增量效果与相关工作比较，不能靠名称或组合数量宣布。
