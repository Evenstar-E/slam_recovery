## 2. 条件式 B：先回答一个可解释的机制问题

当独立正常参照、输入对应和实际干预记录均合格，且具体操作在有效授权内时，建议优先做**一个预先声明机制的有限离线对照**。同一真实输入上比较旧方法和 ALI-H，保留原配置与失败结果。已有材料能回答就先复用；本回复不自行增加新的注入运行额度。

必须满足以下边界：

- **正常校准与评价分开。** 校准段不与事件窗或正常误报评价段重叠；不能看 ALI-H 输出后挑出“正常段”。低支持条件缺正常参照时继续 `OUT_OF_SUPPORT/UNKNOWN`，不借高支持分布。
- **评价答案不进入检测器。** 注入时间表、标签和未来参考仅离线使用；不以 scripted/oracle 触发成绩替代自动检测。
- **说明注入究竟改了什么。** 原始测量、估计状态和地图扰动回答的问题不同；直接改检测分数或强制报警只能检验下游接口。保留执行位置、实际生效区间和强度。
- **区分干预与故障。** 扰动可能被正常吸收；注入 onset 不自动等于定位/地图错误 onset。响应干预和检测已确认错误分开评价，起点不确定则记录区间。
- **按完整声明人口报告。** 未匹配、缺失、尾段、拒绝和失败保留；评价协议中的尾段口径冲突应另记偏离/更正，不能悄改冻结文件来改善分数。
- **一次有限结果不外推。** B 可以形成受控机制证据，不能冒充自然故障泛化、稳定误报率或生产安全认证。

沿 ALI-H 已冻结的首版配置执行，不扫描阈值、缩小正常参照最低支持量或调整旧 sigma/κ/floor 来追求好成绩。若结果负面，保存并解释；不得自动扩矩阵或无假设重跑。

## 3. A：必须补的真实场景验证；C：当前诚实交付

**A 的目标**是用独立确认的正常数据和自然事件依据，验证 B 中观察到的机制能否适用于真实场景。预先区分“环境困难”“实际估计错误”“需要恢复的损害”，不把弱几何本身当作必然故障。说明外部轨迹/几何参考的精度、支持范围和时间坐标对应；仅有代理参考时按代理指标报告。已有 hall/room 开发数据不重新称为未见测试集。没有合格自然事件材料时，将 A 记为后续证据缺口，不虚构已取得新数据。

**C 的用途**是当前按证据范围交付：实际通道、支持条件、UNKNOWN 区间、对应与覆盖限制、成本。C 不代表方法已有效，也不代表方法原理已失败，更不应变成无限工程审计的长期终点。

正常参照与事件标签应分别登记。原记录的“取得两者之一即可最低解除”只能解锁对应部分：**只有标签仍不能完成正常校准，只有正常参照仍不能计算事件漏检与延迟；完整评价需要相应条件共同满足。** 获得用户决定也不能替代科学证据本身。

## 4. 下一交付及验收

下一份实质交付只需合并现有材料形成一次有结论的有限对照，或明确哪个必要条件仍不可得。不另造纯“收到规则”的提交周期。

| 必报内容 | 解释与边界 |
|---|---|
| 正常段误报 | 使用独立正常评价段，报次数和实际曝光；校准数据不能当测试数据，曝光不足不宣稳定率 |
| 漏检与延迟 | 所有预声明、具备标签的事件均计入；没有报警保留 MISS，不只汇总已检测事件 |
| 错误 NORMAL | 异常期间被判正常相容的次数、时长与 scope；相对运动相容不等于绝对地图正确 |
| UNKNOWN | 数量、总时长、最长连续区间及原因；不把弃权当正常或零风险 |
| 旧盲区的实际变化 | 同一评价人口中，旧方法无法判断的哪些区间新增正确判断，新增什么错误 |
| 复现与成本 | source/config/input/calibration/label 身份、实际命令、原件和耗时；相关帧不当独立事件 |
